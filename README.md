### Proyecto destacado

#### [🔧 Gestor de Taller Informático](https://github.com/UlisesGK/Gestor-Taller-IT)

> Aplicación de escritorio para gestionar un taller de reparación de equipos:
> clientes, equipos y órdenes de reparación.

<a href="https://github.com/UlisesGK/Gestor-Taller-IT">
  <img src="https://raw.githubusercontent.com/UlisesGK/Gestor-Taller-IT/main/capturas/app-reparaciones.png" alt="Pantalla de reparaciones" width="620">
</a>

**Qué tiene por dentro:**

- **Arquitectura por capas** — modelo, acceso a datos (DAO) e interfaz, de forma que la
  interfaz no sabe nada de SQL y la capa de datos no sabe nada de Swing
- **SQL real** — `JOIN` de tres tablas, `GROUP BY`, `SUM` y `AVG` para los informes,
  claves foráneas con borrado en cascada e índices
- **Consultas parametrizadas** con `PreparedStatement`, nunca concatenando cadenas,
  para que no haya riesgo de inyección SQL
- **Validaciones de negocio** — fechas coherentes, estados que se ajustan solos
- **Interfaz hecha solo con Swing**, sin librerías de terceros: colores por estado,
  filas alternas y tarjetas de informe
- **Instalador para Windows** generado con `jpackage`, que crea los accesos directos y
  se desinstala desde Configuración de Windows

`Java` `Swing` `SQLite` `JDBC` `POO` `DAO`
